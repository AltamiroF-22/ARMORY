06 Motion / Animation

All animations use GSAP 3.12.5 with ScrollTrigger, Flip and Draggable plugins (free CDN). Smooth scroll is handled by Lenis 1.1.14 integrated into GSAP's ticker.

// Easing CSS custom props (also consumed by GSAP as cubic-bezier strings) --ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1); --ease-in-expo: cubic-bezier(0.7, 0, 0.84, 0); // GSAP ease strings used in JS 'expo.out' → hero reveals, auth open, panel slide 'power2.out' → backdrop fade, counter, nav 'power2.in' → auth close 'expo.inOut' → theme wipe transition

07 Theme System

Theme is stored in 'armory-theme' localStorage key. An inline <script> in <head> applies it before first paint to prevent FOUC.

dark (default)
light
Element Behaviour
#hero Always dark — own CSS var override
#loader Always dark — own CSS var override
#nav-overlay Always dark — own CSS var override
#auth-overlay .auth__visual Always dark — scoped vars on .auth__visual
#auth-overlay .auth__panel Theme-aware — uses var(--color-dark) which flips to parchment
.nav mix-blend-mode:difference — --color-white stays cream for correct inversion
#theme-overlay Full-screen wipe z-10000 · color matches incoming theme bg
// gsap timeline — ThemeToggle#toggle() gsap.timeline() .to(overlay, { scaleX: 1, duration: 0.45, ease: 'expo.inOut' }) .call(() => applyTheme(next)) // swap CSS vars at midpoint .to(overlay, { scaleX: 0, transformOrigin: 'right center', duration: 0.45 });
08 Auth System

Full overlay auth built in js/core/auth.js. No backend — all data persisted to localStorage. Passwords encoded with btoa() (demo obfuscation only).

Key Type Contents
armory-users JSON array [{ name, email, password: btoa(pass) }]
armory-user JSON object { name, email } — current session
armory-theme string 'dark' | 'light'
armory-locale string 'en' | 'pt' | 'de' | 'jp'
// AuthOverlay public API new AuthOverlay().init(); // bind triggers, set GSAP initial state overlay.open('login'); // or 'register' overlay.close(); // backdrop click · ESC · X button // HTML trigger convention <a data-auth-open="login">Login</a> // opens overlay // if session exists → logs out instead
09 Internationalisation
